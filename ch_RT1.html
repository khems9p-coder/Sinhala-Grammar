Section A: Grammar and the Sinhala language (Lesson 1)
Q1. What is the meaning of ව්‍යාකරණය? Give the Hindi word.
Q2. Name the language family of Sinhala.
Q3. What is the usual order of words in a Sinhala sentence?
Q4. Name the subject, object and verb: ළමයා පොත කියවනවා.
Q5. Change into written Sinhala: (a) මං (b) ඔයා (c) ඒක.
Q6. Arrange in the right order: පිසිනවා / බත් / අම්මා.

Section C: Vowel signs and joined letters (Lesson 3)
Q14. Write: ම + ා, ත + ි, ස + ු, ග + ෙ, ප + ො.
Q15. Which vowel signs are written before the consonant?
Q16. Name the sign used in (a) ක්‍රියා (b) ව්‍යාකරණ (c) අර්ථ.
Q17. Write in Sinhala: mother, father, older sister, younger brother.
Q18. Read and write in roman letters: කිරි, පාසල, කෑම.
Section D: Words (Lesson 4)
Q19. Count the syllables: ගුරුවරයා, පාසල, ශිෂ්‍යයා.
Q20. Name the four kinds of words by origin.
Q21. Which Hindi word is related to ගම, අත, කන?
Q22. Add the ending: (a) ගම + ට (b) පොත + ක් (c) ළමයා + ගේ.
Q23. Make a compound: පොත් + හල. What does it mean?
Q24. Write the “write” family: four words with meanings.
Section E: Translation
Q25. Translate into Sinhala: (a) I go home. (b) The student reads a book. (c) We learn Sinhala. (d) The child drinks milk. [4 marks]
Q26. Translate into English: ගුරුවරයා පාසලට යනවා.
