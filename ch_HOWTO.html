mama pothak kiyawanawa.

4. Spoken and written Sinhala are different. When it matters, the book marks them as Spoken (everyday speech) and Written (books, newspapers, letters, exams). Both are taught.
5. Reading the Roman letters. Doubled vowels are long vowels. The same Roman letters are used for similar sounds, so use them as a guide to pronunciation and not as a spelling system. (If Sinhala shows as empty boxes, install the font “Noto Sans Sinhala” or “Iskoola Pota”.)
